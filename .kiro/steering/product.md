# Product Overview

## Purpose

LLM Dashboard is a debugging and monitoring tool for local large language models. It provides comprehensive insights into LLM behavior and performance.

## Core Features

- **Instruction Following Analysis**: Monitor how well LLMs follow instructions
- **Tool Calling Debugging**: Track and analyze tool/function calling behavior
- **Performance Metrics**: Monitor token usage, generation speed, and context window utilization
- **Reasoning Analysis**: Analyze LLM reasoning processes, efficiency, and accuracy
- **Chat Interface**: Interactive chat sessions with LLMs for testing and debugging
- **Settings Management**: Configure interface language, LLM models, and default preferences

## Target Users

Developers and researchers working with local LLMs who need to debug, monitor, and optimize model behavior and performance.
